*Six* é uma coleção de seis jogos com dados de seis faces. Todos se jogam com o
mesmo kit de componentes, e cada jogo tem um nome que quer dizer "seis" em
alguma língua.

Os jogos são independentes: cada capítulo de jogo traz tudo o que é preciso
para aprender aquele jogo, e nenhum depende de outro.

## Como ler este livro

Cada jogo começa com uma visão geral de uma página: o que se faz no turno e
como se vence. Leia a visão geral em voz alta para quem vai jogar e consulte o
resto durante a primeira partida.

As palavras sublinhadas são termos de jogo, com uma definição exata no
glossário, no fim do livro. Cada jogo tem os seus termos.
