# Componentes

Do kit físico (ver [../kit.md](../kit.md)), o Liu usa, com N jogadores:

- N **selos**: um dado de seis faces por jogador, cada um de uma cor que
  nenhum outro dado do jogo tem;
- 16 × N dados comuns, no **saco**: 32 com 2 jogadores, 48 com 3 e 64 com 4.
  Dados brancos e pretos podem se misturar: a cor de um dado comum não conta;
- o saco, de onde os dados comuns saem sem que se veja qual;
- N **molduras**: uma por jogador, uma grade vazada de 4 por 4 casas.

> **Detalhe:** na versão digital não há limite de dados, e todos os dados
> comuns são brancos. O saco continua com 16 × N dados, porque esvaziá-lo
> muda o mercado (ver [03-rodada.md](03-rodada.md#mercado)).
