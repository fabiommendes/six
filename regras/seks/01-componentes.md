# Componentes

Do kit físico (ver [../kit.md](../kit.md)), o Seks usa:

- um tabuleiro de 11 colunas por 11 linhas, com 121 casas;
- 32 dados de seis faces: 16 de uma cor, as **Brancas**, e 16 de outra, as
  **Pretas**.

Os dados nunca são rolados. O jogador gira o dado na mão para mostrar o novo
valor na face de cima.

> **Detalhe:** qualquer dado de seis faces serve, com pontos ou algarismos. A
> casa do tabuleiro precisa ser maior que o dado, com folga para pegar o dado
> sem esbarrar nos vizinhos. Com dados de 16 mm, uma casa de 20 mm dá um
> tabuleiro de 22 cm de lado, mais a margem.

> **Detalhe:** "Brancas" e "Pretas" são só os nomes dos dois lados. Os dados
> podem ter quaisquer duas cores do kit bem distintas.
